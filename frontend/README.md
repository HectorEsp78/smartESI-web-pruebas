# Frontend · Smart ESI Stats

SPA React + Vite + TypeScript con las pestañas **Electricidad** e **Iluminación**.

## Arranque

```bash
npm install
npm run dev        # http://localhost:5174
```

El proxy de Vite envía `/api` a `http://127.0.0.1:8010`.

## Comandos

```bash
npm run typecheck
npm run test:run
npm run build
npm run preview
```
